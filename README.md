## **Recipe Box – Description**

Recipe Box is a mobile application that helps users discover, save, and organize their favorite recipes. It provides an easy and convenient way to find dishes, view ingredients, and follow cooking instructions.

### **Features**

- **Home Page:** Displays featured recipes.
- **Recipe Browsing:** Finds recipes easily.
- **Select A Recipe:** Shows available dishes.
- **Recipe Details:** They can view its details.
- **Ingredients:** Can check the ingredients needed to prapare.
- **Cooking Instructions:** Provides step by step guidance.
- **Save recipes to favorites:** Can save favorites recipes


### **How to Install and Run**

1. Open your project in [FlutterFlow]
2. Click **Run/Test** to preview the application.
3. To install, build an Android APK through the Deployment/Build section.
4. Download the APK and install it on your Android device.
5. Open Recipe Box and start exploring recipes.
